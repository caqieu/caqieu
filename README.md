## 🚀 About me

Backend developer with **5+ years of experience**, focused on **PHP and Laravel**,
building REST APIs and integrations with an emphasis on **performance and
reliability**.

## 🛠️ What I do

- Develop **REST APIs** from scratch, applying SOLID, Clean Code, and design patterns 
- Document contracts with **OpenAPI/Swagger** and **Laravel Scramble** 
- Build integrations with external services, including payment gateways, with retry/backoff 
- Work with databases and caching: **MySQL, PostgreSQL, MongoDB, TimescaleDB, Redis, Laravel Horizon** 
- Ship and operate with **Docker, Linux, Nginx/Cloudflare, GitHub Actions, Jenkins** 
- Monitor production with **New Relic** and **Laravel Telescope** 
- Cover quality with **PHPUnit/Pest**, E2E tests, **PHPStan/PHPCS/PHPMD**, and TDD 
- Use AI in my workflow with **Codex CLI** and **Claude Code**, and build integrations via **MCP**
